# SolarCalc Pro

## Описание проекта

SolarCalc Pro — веб-платформа для расчёта и проектирования солнечных электростанций частных домов. Система рассчитывает потребление электроэнергии дома, определяет приход солнечной радиации по координатам, подбирает мощность массива панелей, ёмкость накопителя и инвертор, размещает панели на снимке крыши, формирует варианты комплектации из реального каталога оборудования и готовит коммерческое предложение.

Основными пользователями системы являются домовладельцы и администратор каталога оборудования.

---

# Пользовательские роли

## Гость

Домовладелец без учётной записи. Выполняет расчёт и получает коммерческое предложение без регистрации.

Основные функции:

* ввод потребления;
* выбор локации;
* размещение панелей на крыше;
* расчёт станции;
* сравнение вариантов комплектации;
* формирование коммерческого предложения.

## Пользователь

Зарегистрированный домовладелец.

Основные функции:

* все функции гостя;
* регистрация и авторизация;
* сохранение проектов;
* просмотр, дублирование и удаление своих проектов.

## Администратор каталога

Сотрудник магазина оборудования.

Основные функции:

* ведение каталога панелей, инверторов и аккумуляторов;
* управление ценами и ссылками на товары;
* просмотр сводки по системе.

---

# Основные сущности системы

В информационной системе используются следующие ключевые сущности:

1. Пользователь (User);
2. Проект (Project);
3. Расчёт (Calculation);
4. Вариант комплектации (Configuration);
5. Товар каталога (Product);
6. Коммерческое предложение (Offer).

---

# Архитектура системы

Архитектура приложения построена по клиент-серверному принципу.

Frontend реализован на Next.js и React и обеспечивает пошаговый сценарий расчёта, редактор крыши, графики и предпросмотр коммерческого предложения.

Backend реализован на FastAPI и содержит расчётное ядро, подбор оборудования, управление проектами, авторизацию и справочники. Все инженерные формулы выполняются на сервере.

Для хранения данных используется СУБД PostgreSQL.

Климатология солнечной радиации запрашивается у NASA POWER и кэшируется в базе данных.

# Диаграмма контейнеров C4

Система включает следующие контейнеры:

* Клиент в браузере (React 19);
* Веб-сервер приложения (Next.js 15);
* Backend API (FastAPI);
* База данных (PostgreSQL).

Взаимодействие осуществляется по протоколу HTTPS через REST API с авторизацией по JWT.

---

# База данных

Структура базы данных разработана в соответствии с требованиями третьей нормальной формы (3NF).

Основные сущности связаны отношениями:

* пользователь владеет проектами;
* проект содержит профиль потребления и скаты крыши;
* проект порождает расчёты;
* расчёт предлагает варианты комплектации;
* вариант комплектации состоит из товаров каталога;
* по варианту формируется коммерческое предложение.

Описание архитектуры и ER-диаграмма приведены в файле [ARCHITECTURE.md](ARCHITECTURE.md).

# Заключение

Разработанная архитектура SolarCalc Pro разделяет ответственность между клиентом, сервером и базой данных и сосредотачивает инженерный расчёт на сервере, что обеспечивает единый результат во всех частях системы, упрощает тестирование расчётного ядра и позволяет развивать клиент независимо от формул.
